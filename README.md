# Chest Collector

A simple single-file incremental / idle game.

## How to play

1. Open `index.html` in any modern browser (or view it via GitHub Pages).
2. Buy chests (the first Common chest is free).
3. Items from chests earn coins per second.
4. Use coins to buy better chests.
5. Every 15th chest requires a short math question.
6. Rebirth to double your coin income permanently (resets progress).
7. Unlock Battle mode at 10 billion coins — fight monsters for battle coins that permanently boost income.

## Features

- 3 independent save slots (localStorage)
- Multiple rarity tiers of chests and items
- Rebirth system with escalating costs
- Battle / monster fighting system
- Math quiz gate every 15 chests
- Dark mode support via `prefers-color-scheme`
- Fully offline / no backend required

## Play

Just open **index.html**.
